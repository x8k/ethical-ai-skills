## 🎯 The Good Will

**Definition**: "It is impossible to think of anything at all in the world, or indeed even beyond it, that could be considered good without limitation except a good will." (4:393)

## ⚖️ Duty vs. Inclination

### The Motive Test

| MOTIVE | EXAMPLE | MORAL WORTH | TEST |
|--------|---------|--------------|------|
| From Inclination | "I'm honest because it's good for business" | ❌ None | Would you do this if it cost you? |
| From Duty + Inclination | "I'm honest because it's right AND good for business" | ❌ None | Inclination might be the real motive |
| From Duty | "I'm honest because it's the right thing to do, even if it costs me" | ✅ Full | Duty alone moves the will |

**Key Question**: "Would you do this action even if it brought you no benefit and caused you harm?"
- **Yes** → Possibly from duty → Moral worth
- **No** → From inclination → No moral worth

## 🏆 The Categorical Imperative

### Three Formulations

```
┌─────────────────────────────────────────────────────────────┐
│  FORMULATION 1: UNIVERSAL LAW (4:421)                         │
│  "Act only according to that maxim whereby you can, at the       │
│   same time, will that it should become a universal law."      │
│                                                                 │
│  HOW TO APPLY:                                                  │
│  1. Formulate your maxim                                        │
│  2. Imagine it as universal law                                 │
│  3. Ask: Could this law be willed without contradiction?       │
│  4. If NO → Impermissible                                       │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  FORMULATION 2: HUMANITY AS END (4:429)                        │
│  "Act in such a way that you treat humanity, whether in your    │
│   own person or in the person of any other, never merely as   │
│   a means to an end, but always at the same time as an end."   │
│                                                                 │
│  HOW TO APPLY:                                                  │
│  1. Identify all affected parties                               │
│  2. Ask: Am I using anyone merely as a means?                    │
│  3. Ask: Am I respecting each person's rational nature?          │
│  4. If anyone used as mere means → Impermissible                │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  FORMULATION 3: AUTONOMY / KINGDOM OF ENDS (4:431, 4:439)      │
│  "So act that your will can regard itself at the same time as    │
│   making universal law through its maxims."                   │
│  "All maxims... ought to harmonize with a possible kingdom     │
│   of ends as a kingdom of nature."                             │
│                                                                 │
│  HOW TO APPLY:                                                  │
│  1. Imagine a community of rational legislators                   │
│  2. Ask: Could my maxim be a law in this community?              │
│  3. Ask: Am I acting as a self-legislator?                       │
│  4. If yes to both → Permissible                                 │
└─────────────────────────────────────────────────────────────┘
```

**All Three Say the Same Thing**: The categorical imperative is one principle expressed in three ways.

## 📋 The Four Examples (Section II)

| EXAMPLE | MAXIM | UNIVERSAL LAW TEST | HUMANITY TEST | VERDICT |
|---------|-------|---------------------|---------------|---------|
| Lying Promise | "I may make a lying promise when in distress" | Contradiction in conception (promising would be impossible) | Uses promisee as mere means | ❌ Impermissible |
| Suicide from Despair | "I may shorten my life when it brings more pain than pleasure" | Contradiction in will (contradicts self-preservation) | Uses oneself as mere means to happiness | ❌ Impermissible |
| Neglecting Talents | "I may neglect the cultivation of my talents" | Contradiction in will (wastes rational nature) | Fails to develop one's humanity | ❌ Impermissible |
| Refusing to Help | "I may refuse to help others in need" | Contradiction in will (contradicts end of happiness) | Uses others as mere means to one's own ends | ❌ Impermissible |

**Key Insight**: All four fail the categorical imperative test, showing that common "exceptions" to moral rules are actually impermissible.

## 🆚 Hypothetical vs. Categorical Imperatives

```
┌───────────────────────────────┐  ┌───────────────────────────────┐
│     HYPOTHETICAL IMPERATIVE     │  │    CATEGORICAL IMPERATIVE      │
├───────────────────────────────┤  ├───────────────────────────────┤
│ Form: "If you will X, then do Y" │  │ Form: "Do Y" (unconditionally)   │
│ Basis: Conditional on desires    │  │ Basis: Reason itself            │
│ Source: Reason as instrument    │  │ Source: Reason as practical     │
│ Example: "If you want health,     │  │ Example: "Do not lie"          │
│          exercise"               │  │                                │
│ Moral Status: ❌ Not moral       │  │ Moral Status: ✅ Moral          │
│ Types: Problematic, Assertoric   │  │ Types: Apodictic                │
└───────────────────────────────┘  └───────────────────────────────┘
```

**Remember**: Only categorical imperatives are moral. Hypothetical imperatives are merely prudent.

## 💡 The Three Tests (Quick Reference)

### 1. Universalizability Test
```
Question: Could everyone do this?
If NO → Impermissible
If YES → Continue to next test
```

### 2. Respect for Persons Test
```
Question: Am I treating anyone merely as a means?
If YES → Impermissible
If NO → Continue to next test
```

### 3. Legislative Test
```
Question: Could this be a law in the kingdom of ends?
If NO → Impermissible
If YES → ✅ Permissible
```

## 🎓 Kant's Moral Method in 5 Steps

1. **Identify the Maxim**: What rule are you following?
2. **Test with Categorical Imperative**: Could this be universal law?
3. **Check Respect for Persons**: Are you treating anyone as mere means?
4. **Verify Autonomy**: Are you legislating for yourself?
5. **Act**: If all tests pass, the action is morally permissible

---

## 🔑 Key Kantian Principles

1. **Good Will Principle**: Only the good will is good without limitation.
2. **Duty Principle**: An action has moral worth only if done from duty.
3. **Universalizability Principle**: Act only on maxims that can be universal law.
4. **Humanity Principle**: Always treat persons as ends, never merely as means.
5. **Autonomy Principle**: The will must be a law to itself.
6. **Primacy Principle**: Practical reason has priority over theoretical reason in moral matters.

---

## 💬 Kant in One Sentence Each

1. **The Supreme Good**: The good will is the only thing good without limitation.
2. **Moral Worth**: Actions have moral worth only when done from duty, not inclination.
3. **The Moral Law**: The categorical imperative is the supreme principle of morality.
4. **Universalizability**: An action is moral only if its maxim can be willed as universal law.
5. **Human Dignity**: Persons must be treated as ends in themselves, never merely as means.
6. **Autonomy**: Morality requires that the will give the law to itself.
7. **Heteronomy Rejected**: Morality cannot come from desire, self-interest, or external authority.
8. **Postulates**: Immortality, freedom, and God are necessary conditions for the highest good.
9. **Primacy of Practical Reason**: Morality has priority over theoretical knowledge when they conflict.
10. **The Foundation**: Autonomy is the foundation of the dignity of all rational nature.
