# Cheatsheet - Risorse Educative Aperte (OER)

## Definizione OER (UNESCO 2002)
Materiali didattici in formato digitale o altro, offerti **gratuitamente e aperte** per:
- **Consultazione**
- **Uso**
- **Adattamento**
- **Condivisione**

## 4 Pilastri OER
| Principio | Descrizione | Esempio |
|-----------|-------------|---------|
| **Apertura** | Accesso gratuito per tutti | Repository OER accessibili |
| **Tecnologie di rete** | Distribuzione via web | Piattaforme online |
| **Uso e riuso** | Modificabilità e adattamento | Licenze CC-BY |
| **Scopi non commerciali** | Condivisione gratuita | Non profit |

## Licenze Creative Commons
| Sigla | Nome | Simbolo | Permessi |
|-------|------|---------|----------|
| BY | Attribuzione | ✓ | Condividi, modifica, commerciale (obbligo citare autore) |
| BY-SA | Attribuzione - Condividi allo stesso modo | ✓ | Modifiche con stessa licenza |
| BY-NC | Attribuzione - Non commerciale | ✓ | No uso commerciale |
| BY-ND | Attribuzione - Non opere derivate | ✓ | No modifiche |
| BY-NC-SA | Attribuzione - Non commerciale - Condividi allo stesso modo | ✓ | Combina NC + SA |
| BY-NC-ND | Attribuzione - Non commerciale - Non opere derivate | ✓ | Più restrittiva |

## Modello AMELIS
```
Collaborazione → Co-progettazione → Sperimentazione
         ↓              ↓               ↓
  Valutazione    Produzione      Scambio
     tra pari   risorse OER    risorse
```

## Vantaggi OER
1. **Riduzione costi**: Accesso gratuito vs. editoria commerciale
2. **Qualità**: Controllo condiviso dalla comunità
3. **Innovazione**: Aggiornamento continuo e collaborativo
4. **Flessibilità**: Adattamento a contesti specifici
5. **Formazione continua**: Accesso a risorse per sviluppo professionale

## Criticità OER
1. **Sostenibilità**: Modelli economici a lungo termine
2. **Qualità**: Garanzia e certificazione
3. **Adozione**: Resistenza al cambiamento nella scuola
4. **Competenze digitali**: Necessità di formazione docenti
5. **Licenze**: Complessità giuridica

## Frameworks Chiave
- **Open Education**: Conoscenza come bene pubblico
- **Software Libero/Open Source**: 4 libertà (GPL)
- **Open Content**: Contenuti aperti (David Wiley)
- **Creative Commons**: Licenze aperte per contenuti
- **Co-progettazione**: Lavoro collaborativo tra insegnanti

## Metodologia AMELIS
1. Progettazione collaborativa (Moodle)
2. Produzione risorse multimediali
3. Sperimentazione in codocenza
4. Valutazione reciproca
5. Scambio tra scuole

## Tipologie Risorse AMELIS
- Presentazioni multimediali
- Video didattici
- Esercizi linguistici interattivi
- Giochi didattici multilingue
- Schede metodologico-didattiche
