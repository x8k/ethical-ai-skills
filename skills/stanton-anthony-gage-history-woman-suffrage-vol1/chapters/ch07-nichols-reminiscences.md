# Chapter 7: Reminiscences by Clarina I. Howard Nichols

## Core Idea
Multi-state organizing efforts by Clarina I. Howard Nichols, documenting women's rights work in Vermont, Wisconsin, Kansas, and Missouri.

## Key Concepts
- Vermont: Property Laws (1847, 1849), school suffrage
- Wisconsin: State Temperance Society, opposition of clergy
- Kansas: Free State Emigration (1854), Constitutional Convention (1859)
- Missouri: Lecturing, John Brown raid connections
- Women's State Temperance Society
- Lydia F. Fowler
- John O. Wattles
- Francis Jackson Fund

- Use comparative state analysis to understand regional variations
